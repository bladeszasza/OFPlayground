## Release decisions and limits

The user supplied Bolyos Csaba <bladeszasza@gmail.com> on 2026-11-04 and authorized pushing to bladeszasza/OFPlayground. That identity is configured only in this repository. The historical `working-2.0` tag is preserved. The release uses an annotated v0.3.0 tag for the combined tested implementation; the proposed 0.2.0 checkpoint remains untagged. The final frontend bundle SHA-256 is `bcff4c5a36c9596a7edb33b86b3b536acaf6cb6e098854c024eb5b6faf84232b`. The annotated tag must resolve to the tested source commit. No earlier 0.2.0 release or package publication is implied.

The optional web extra still has Gradio 6.31.0's Pillow <13 constraint, while the audited Pillow fixes require 13.0.0. The compatible version was restored after the resolver conflict was reproduced. Core/Canvas installs avoid that dependency. This is a documented exception, not a clean all-extras security claim.

Provider account compatibility has not been paid-tested. Canceling a local await cannot retract a submitted remote job or kill its HTTP worker thread; adapters suppress stale output and own bounded local teardown. Remote OFP participants without trusted ASP reports remain unknown. ASP does not detect compromise automatically. This release is local-first; federation, public multi-tenancy, editable workflow DAG routing, active probes and OTLP ingest remain outside its profile.

Status payload/event/observer queues and Canvas presentation are bounded. Durable dedup IDs grow with accepted events; per-agent task scopes are capped by the local profile. Operators running very long-lived workloads need a retention/capacity policy. Source checkout distribution, the optional dependency exception, provider validation and architecture simplification remain the largest follow-up areas.
